# Baseus Controller Mac

A macOS application to connect to and control Baseus headphones, featuring spatial audio, noise cancellation profiles, and more directly from your Mac's menu bar.

## Features

- **Menu Bar Controls:** Easily control your headset via the status bar.
- **Noise Cancellation Profiles:** Switch between Commuting, Indoor, and Outdoor ANC modes.
- **Spatial Audio:** Toggle spatial audio modes (Music, Movie, None).
- **Settings:** Quick toggles for Bass Boost, LDAC, and Start at Login.
